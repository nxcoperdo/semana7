# semana7

Java exercise on object-oriented inheritance, applied to library materials.

## What it contains

- `MaterialBiblioteca`: base class with title and author properties (getters/setters).
- `Libro`: subclass that adds a genre and a `mostrarInfo()` method.
- `Revista`: subclass that adds an issue number.
- `Main`: entry point.

## Stack

Java, Maven (`pom.xml`).

## How to run

Open the project in an IDE (IntelliJ IDEA) and run `org.example.Main`, or build with Maven (`mvn compile`).
